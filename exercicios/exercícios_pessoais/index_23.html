Nome do Mês com switch

Objetivo: Praticar a estrutura switch para valores fixos e o uso do break.
Tarefa: Crie uma interface onde o usuário digita o número de um mês (1 a 4) em um campo <input>.
Ao clicar em um botão, use a estrutura switch para verificar o número:
Case 1: Exiba "Janeiro".
Case 2: Exiba "Fevereiro".
Case 3: Exiba "Março".
Case 4: Exiba "Abril".
Default: Exiba "Mês não mapeado".
Importante: Não esqueça de colocar o comando break após cada caso para evitar que o código "caia" nos próximos.

Digite um número de 1 a 12 para descobrir o mês!
