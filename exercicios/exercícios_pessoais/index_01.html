Registro de Usuário e Manipulação de Texto

Objetivo: Praticar a captura de dados, uso de variáveis e métodos de string.
Tarefa: Crie um script que:
Peça o nome completo do usuário usando window.prompt().
Armazene esse nome em uma variável.
Exiba um alerta (alert) mostrando:
Exiba na página web
O nome todo em letras maiúsculas.
O nome todo em letras minúsculas.
Quantas letras o nome possui (considerando espaços).
