Conversor de Moeda e Formatação

Objetivo: Praticar a formatação de números e o uso de constantes.
Tarefa: Imagine que você está criando um sistema financeiro. Faça um script que:
Declare uma variável com let ou const para receber um valor numérico decimal (ex: um salário)
Formate esse número para que ele mostre apenas duas casas decimais usando .toFixed(2).
Em seguida, exiba esse mesmo valor formatado como moeda brasileira (R$) utilizando o método .toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' }).
