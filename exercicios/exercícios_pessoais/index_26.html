Verificador de Turno e Saudação

Objetivo: Criar um sistema que, ao clicar em um botão, capture a hora do sistema e diga se é manhã, tarde, noite ou madrugada, mudando a cor do fundo.
Regra: Use new Date().getHours() diretamente na comparação do if.
Desafio: Tente fazer o código sem criar uma variável para o objeto Date, capturando a hora assim: let hora = new Date().getHours().
