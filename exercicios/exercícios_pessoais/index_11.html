Manipulando Coleções de Elementos

Objetivo: Praticar a seleção múltipla e o uso de loops para aplicar estilos.
Tarefa:
Crie uma lista (pode ser várias tags

) onde todas tenham a class="item-lista".
No seu script JavaScript:
Selecione todos esses elementos de uma vez usando document.getElementsByClassName('item-lista') ou document.querySelectorAll('.item-lista').
Use um laço de repetição (for) para percorrer todos os itens selecionados.
Dentro do laço, altere o tamanho da fonte (fontSize) de cada um para "20px" e coloque o texto em itálico.
