Seletores Modernos e Conteúdo HTML

Objetivo: Praticar o uso de querySelector e a diferença entre innerText e innerHTML.
Tarefa:
Crie um header que contenha um título -h1- e um -span- dentro de um parágrafo.
No seu script JavaScript:
Use o document.querySelector() para selecionar o primeiro -span- que encontrar na página.
Altere o conteúdo desse elemento usando innerHTML, inserindo uma tag de negrito: mySpan.innerHTML = 'Texto importante!'.
Use o querySelector novamente para selecionar o h1 e mude o alinhamento do texto para o centro usando style.textAlign = 'center'.
