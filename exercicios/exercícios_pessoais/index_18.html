Contador de Cliques e Escopo

Objetivo: Compreender o escopo de variáveis e a atualização dinâmica de conteúdo.
Tarefa: Crie um botão escrito "Contar" e um parágrafo que diga "Cliques: 0".
Declare uma variável contador fora de qualquer função (escopo global para este script) e inicie-a com 0.
Crie uma função que, cada vez que o botão for clicado:
Incremente a variável contador.
Atualize o texto do parágrafo usando Template Literals para mostrar o novo valor.
Dica do Guia: Use o Console do navegador (DevTools) para verificar se a variável está aumentando corretamente caso o texto não mude.
