Sistema de Votação (Condição Simples)

Objetivo: Aplicar uma condição simples onde uma ação só ocorre se um critério específico for atingido.
Tarefa: Crie um sistema que verifique se uma pessoa já tem idade para votar (considere a idade mínima de 16 anos para este exercício).
No HTML, crie um campo para digitar a idade (<input type="number">) e um botão para validar.
No JavaScript, crie uma função que:
Converta o valor do input para um número usando Number().
Use uma condição simples (if):
Se a idade for maior ou igual a 16, adicione a mensagem: "Você já pode votar!".
Fora da condição (para que apareça sempre), exiba a mensagem: "Verificação de idade concluída."
