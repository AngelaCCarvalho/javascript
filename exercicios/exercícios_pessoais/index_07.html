Comparação de Identidade (Valor vs. Tipo)

Objetivo: Entender a diferença entre == (igualdade) e === (identidade/estritamente igual).
Tarefa: Crie um script que:
Declare uma variável numero com o valor numérico 10.
Declare uma variável texto com a string '10'.
Use console.log ou document.write para mostrar o resultado das seguintes comparações:
numero = = texto (Verifica apenas o valor).
numero = = = texto (Verifica valor e tipo).
numero ! = = texto (Verifica se são estritamente diferentes).
Adicione um comentário no código explicando por que a segunda comparação resultou em false.
