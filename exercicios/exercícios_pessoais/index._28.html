Exercício 3: Validador de Cartão de Crédito (Validade) Objetivo: Criar um campo onde o usuário digita o ano de validade do cartão (4 dígitos). O sistema deve dizer se o cartão está "EXPIRADO" ou "VÁLIDO". Regra: O cartão é considerado expirado se o ano digitado for menor que o ano atual do sistema. Simplificação: Não crie variáveis para os elementos HTML que você não vai usar mais de uma vez. Vá direto ao .value.
