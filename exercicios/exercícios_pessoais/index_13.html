Alteração em Massa com QuerySelectorAll

Objetivo: Praticar o uso de seletores CSS complexos e loops.
Tarefa:
Crie uma lista não ordenada (-ul>) com 5 itens (-li>).
No seu JavaScript:
Selecione todos os itens da lista usando document.querySelectorAll('ul li').
Use um laço for para percorrer a coleção.
Se o índice do item for par (dica: i % 2 === 0), mude a cor de fundo para cinza claro.
Se for ímpar, mude para branco.
